# Lumi Clock - Immersive Productivity Web App

Lumi Clock is a clean, minimalist, and immersive web application designed to create a focused environment for work or study. It replaces a cluttered desktop with a beautiful, functional, and distraction-free interface.

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge)](https://lumi-clock.vercel.app/)

### 🎯 The Problem

In a world full of digital distractions, finding a quiet space to focus is difficult. Standard desktop environments are filled with notifications and icons. Lumi Clock was built to solve this by providing a single, elegant screen with only the essential tools you need for a productive session.

---

###  🛠️ Tech Stack

- **Frontend:** React.js, HTML5, CSS3
- **Deployment:** Vercel

---

###  ✨ Features

- **Live HD Video Background:** A calming, dynamic background to help you stay relaxed.
- **Essential Productivity Tools:** Includes a clean Notepad, a simple Timer, and a Calendar.
- **Daily Motivational Quotes:** A new quote every day to keep you inspired.
- **Lock Mode:** Hides all tools to provide a completely immersive, video-only experience for maximum focus.
- **Unlock Mode:** Brings back all tools for full access and functionality.
- **Modular & Responsive:** Built with clean, reusable React components for fast performance on any device.

---

### 🚀 Running Locally

To run Lumi Clock on your local machine:

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/ashmitasenroy/lumi-clock.git
    ```

2.  **Navigate into the directory:**
    ```sh
    cd bloom
    ```

3.  **Install dependencies:**
    ```sh
    npm install
    ```

4.  **Start the development server:**
    ```sh
    npm start
    ```
    The application will be available at `http://localhost:3000`.
